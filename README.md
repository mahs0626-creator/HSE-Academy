# HSE Academy

Flutter mobile learning platform for professional HSE education.

## v1.1.0
- Course/lesson architecture
- OSHA Fundamentals with 6 lessons
- Lesson knowledge checks and scoring
- Per-user lesson progress stored locally
- Course progress dashboard
- HSE Pro 12-week structure
- Profile fields and profile photo
- Existing GitHub Actions Android APK workflow retained

The OSHA curriculum is an educational implementation and is not an OSHA endorsement or certification.
